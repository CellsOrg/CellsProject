# 한화이글스 부서별 Workflow

## 1. 문서 목적

한화이글스 구단의 업무를 담당하는 6개 팀의 Workflow를 정리한다.

- 마케팅팀
- 티켓팀
- 멤버십팀
- 굿즈팀
- 고객지원팀
- 스폰서십팀

각 Workflow는 **기획 → 실행 → 팬 행동 발생 → 데이터 축적 → 분석 → 후속 행동**의 관점에서 구성한다.

---

## 2. 마케팅팀

> **시장·팬 분석 → 캠페인 기획 → 대상 세분화 → 발송 대상 확정 → 캠페인 실행 → 반응 모니터링 → 성과 분석**

| 단계 | 업무 | 주요 내용 |
| --- | --- | --- |
| 1 | 시장·팬 분석 | 신규 팬·충성 팬·이탈 팬의 규모와 특성을 분석한다. |
| 2 | 캠페인 기획 | 어떤 팬에게 어떤 메시지·혜택·콘텐츠를 제공할지 결정한다. |
| 3 | 대상 세분화 | 관람 이력, 구매 이력, 관심도 등을 기준으로 팬 세그먼트를 생성한다. |
| 4 | 발송 대상 확정 | 캠페인 조건 충족 여부와 마케팅 수신 가능 여부를 확인하여 실제 발송 대상을 확정한다. |
| 5 | 캠페인 실행 | 경기 정보, 콘텐츠, 쿠폰, 프로모션 등의 메시지를 발송한다. |
| 6 | 반응 모니터링 | 열람, 클릭, 이벤트 참여, 구매 등 팬의 반응 행동을 확인한다. |
| 7 | 성과 분석 | 캠페인을 통한 매출, 재방문, 굿즈 구매, 멤버십 전환 등의 성과를 측정한다. |

---

## 3. 티켓팀

> **판매 준비 → 자격 확인 → 예매 → 티켓 발급 → 선물·양도 → 입장 → 문제 처리 → 관람 분석**

| 단계 | 업무 | 주요 내용 |
| --- | --- | --- |
| 1 | 판매 준비 | 경기, 좌석, 등급별 판매 정책과 가격을 설정한다. |
| 2 | 자격 확인 | 멤버십 선예매, 할인, 어린이·학생 등 구매 자격을 확인한다. |
| 3 | 예매 | 팬이 경기와 좌석을 선택하고 결제하도록 처리한다. |
| 4 | 티켓 발급 | 예매 완료 후 스마트티켓을 발급한다. |
| 5 | 선물·양도 | 티켓 구매자가 실제 관람자에게 티켓을 이전할 수 있도록 처리한다. |
| 6 | 입장 | 경기장 게이트에서 티켓을 인증하고 실제 입장 여부를 기록한다. |
| 7 | 문제 처리 | 티켓 발급 오류, 취소·환불, 양도, 입장 오류 등을 처리한다. |
| 8 | 관람 분석 | 실제 입장, 노쇼, 관람 횟수, 반복 관람 등 팬의 관람 패턴을 분석한다. |

---

## 4. 멤버십팀

> **팬 분석 → 멤버십 상품 기획 → 가입 → 활성화·발급 → 혜택 운영 → 이용 분석 → 갱신 관리**

| 단계 | 업무 | 주요 내용 |
| --- | --- | --- |
| 1 | 팬 분석 | 관람 빈도, 구매액, 팬 특성, 혜택 이용 패턴 등을 분석한다. |
| 2 | 멤버십 상품 기획 | 멤버십 등급, 가격, 혜택, 선예매 정책 등을 설계한다. |
| 3 | 가입 | 신규 멤버십 신청, 결제, 가입 절차를 처리한다. |
| 4 | 활성화·발급 | 회원 자격을 활성화하고 디지털 멤버십 또는 멤버십 카드를 발급한다. |
| 5 | 혜택 운영 | 선예매, 할인, 멤버십 데이 등 회원 혜택을 제공하고 사용 자격을 검증한다. |
| 6 | 이용 분석 | 관람 횟수, 혜택 사용, 구매, 이벤트 참여 등 멤버십 이용 행동을 분석한다. |
| 7 | 갱신 관리 | 멤버십 만료를 안내하고 다음 시즌 갱신 대상자를 선정하여 갱신을 유도한다. |

---

## 5. 굿즈팀

> **수요 분석 → 상품 기획 → 출시 대상 선정 → 개인화 추천 → 혜택 적용 → 주문 처리 → 배송 관리 → 교환·반품 → 재구매 분석**

| 단계 | 업무 | 주요 내용 |
| --- | --- | --- |
| 1 | 수요 분석 | 어떤 선수, 상품, 카테고리에 팬의 관심과 구매 수요가 높은지 파악한다. |
| 2 | 상품 기획 | 유니폼, 키링, 응원용품 등 출시할 상품을 기획한다. |
| 3 | 출시 대상 선정 | 어떤 선수, 기록, 이벤트 등을 소재로 굿즈를 제작할지 결정한다. |
| 4 | 개인화 추천 | 구매 이력, 관심 상품 등에 따라 팬별로 적합한 상품을 추천한다. |
| 5 | 혜택 적용 | 멤버십 할인, 쿠폰 등 팬이 사용할 수 있는 구매 혜택을 검증하고 적용한다. |
| 6 | 주문 처리 | 상품 주문과 결제를 처리한다. |
| 7 | 배송 관리 | 상품 발송과 배송 상태를 관리한다. |
| 8 | 교환·반품 | 상품 문제에 따른 교환 및 반품 요청을 처리한다. |
| 9 | 재구매 분석 | 팬별 구매 이력을 분석하여 재구매 가능 상품과 후속 캠페인을 도출한다. |

---

## 6. 고객지원팀

> **문의 접수 → 본인 확인 → 문의 파악 → 유형별 처리 → 해결·이관 → 문의 종료 → 재발 방지**

| 단계 | 업무 | 주요 내용 |
| --- | --- | --- |
| 1 | 문의 접수 | 전화, 앱, 웹 등 채널별로 팬의 문의 내용을 접수하고 기록한다. |
| 2 | 본인 확인 | 구매자·회원 여부와 Fan ID 등 고객 식별 정보를 확인한다. |
| 3 | 문의 파악 | 팬이 겪는 문제와 요구 사항을 구체적으로 확인한다. |
| 4 | 유형별 처리 | 문의를 티켓, 멤버십, 굿즈, 경기장 이용 등 적절한 유형으로 분류하여 처리한다. |
| 5 | 해결·이관 | 고객지원팀이 직접 해결하거나 전문 처리가 필요하면 담당 부서로 이관한다. |
| 6 | 문의 종료 | 해결 내용과 팬의 최종 반응, 만족도 등을 기록하고 Case를 종료한다. |
| 7 | 재발 방지 | 반복 문의와 불만의 원인을 분석하여 서비스·운영 개선에 반영한다. |

### 문의 유형 예시

```text
문의 파악
├─ 티켓 문제: 발급·취소·환불·양도·입장
├─ 멤버십 문제: 자격·혜택·갱신·환불
├─ 굿즈 문제: 주문·배송·교환·반품
└─ 기타 문제: 경기장 시설·서비스 등
```

## 7. 스폰서십팀

> **스폰서십 상품 기획 → 스폰서 발굴 → 제안 → 계약 → 캠페인 설계 → 실행 → 성과 측정 → 재계약**

| 단계 | 업무 | 주요 내용 |
| --- | --- | --- |
| 1 | 스폰서십 상품 기획 | 광고, 브랜드데이, 팬 이벤트 등 스폰서에게 제공할 권리와 패키지를 구성한다. |
| 2 | 스폰서 발굴 | 구단의 팬층 및 브랜드 이미지와 적합한 기업·브랜드를 탐색한다. |
| 3 | 제안 | 예상 노출, 팬 특성, 참여 규모 등을 포함한 스폰서십 제안서를 작성하고 제안한다. |
| 4 | 계약 | 스폰서 제공 권리, 계약 금액, 기간, KPI 등을 확정한다. |
| 5 | 캠페인 설계 | 어떤 팬에게 어떤 스폰서 혜택·프로모션·이벤트를 제공할지 결정한다. |
| 6 | 캠페인 실행 | 브랜드데이, 쿠폰, 체험 부스, 팬 이벤트 등의 스폰서 캠페인을 운영한다. |
| 7 | 성과 측정 | 노출, 이벤트 참여, 쿠폰 사용, 구매 등 캠페인의 성과를 분석한다. |
| 8 | 재계약 | 캠페인 성과 자료를 바탕으로 스폰서에게 재계약 또는 확대 계약을 제안한다. |
