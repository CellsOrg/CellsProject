### 매장 소개

을지로 오피스 상권에서 3년째 운영 중인 수제버거 가게. 평일엔 인근 직장인, 주말엔 관광객이 주 고객이다. 사장님 함부기가 점주 겸 매니저로 운영을 총괄하고, 아르바이트 3명이 교대로 근무한다.

올해만 직원이 5명 교체됐다 — 이유는 "직원 교육이 제대로 이루어지지 않아서". 지금도 기존 직원 1명이 퇴사하고 신입(김스태프)이 막 들어온 상태다. Tongss가 풀어야 할 문제가 이 매장 안에 그대로 담겨 있다.

### Tongss가 이 매장에서 해결하는 문제

이 매장의 이야기(직원 5명 교체, 매번 처음부터 가르치는 함부기)는 Tongss가 풀려는 문제를 그대로 보여줍니다. 아래 목록이 이 문서의 매뉴얼(§4)·체크리스트(§5) 예시가 존재하는 이유입니다.

- **반복되는 신입 교육** — 직원이 바뀔 때마다 매번 처음부터 가르쳐야 한다
- **읽히지 않는 매뉴얼** — 매뉴얼을 만들어도 배포와 학습은 별개 문제다
- **일관되지 않은 고객 응대** — 누가 근무하느냐에 따라 서비스 품질이 달라진다
- **똑같은 질문의 반복** — 사장이 같은 질문에 몇 번이고 다시 답해야 한다
- **오늘 할 일이 됐는지 알 수 없음** — 체크리스트로 정한 업무(재고 확인 포함)를 실제로 했는지 사장이 확인할 방법이 없다

### 사장님: 함부기

| 항목 | 내용 |
|---|---|
| 이름 | 함부기 |
| 나이 / 성별 | 35세 / 남성 |
| 직책 | 매장 대표이자 운영 책임자 |
| 주요 역할 | 매장 운영, 메뉴개발, 발주, 직원교육, 고객응대, 마케팅 |
| 근무시간 | 평일 하루 평균 14시간 |
| 디지털 숙련도 | POS·배달앱·모바일뱅킹은 익숙, 복잡한 초기 설정·데이터 입력은 부담 |
| 성향 | 성질 급함, 꼼꼼하지 못함, 호탕함, 은근 정 있음 |
| 최근 상황 | 신혼, 2개월 뒤 출산 예정 |

**페인포인트** (`01_PERSONAS.md` "이대표"와 동일한 맥락)
1. 신입 교육이 스트레스다 — 매번 처음부터, 매번 혼자
2. 체크리스트가 안 지켜진다 — 만들어놔도 현장에서 무시된다
3. 매뉴얼을 안 읽는다 — 배포와 학습은 다른 문제
4. 누가 뭘 했는지 모른다 — 물어봐야만 안다

## 4. 예시 매뉴얼

> Tongss가 저장하는 건 **레시피가 아니라 운영 지식**입니다. 그래서 예시도 주방 일에 그치지 않고, 매장을 실제로 돌아가게 하는 네 영역으로 나눴습니다. 아래는 예시일 뿐이라 설명은 짧게만 적었습니다 — 실제 매뉴얼은 사장이 사진 한 장 + 한 줄로 채웁니다 (`00_PRODUCT_GUIDE.md` 참조).

### 매장 운영 (Store Operations)

| 제목 | 예상 소요시간 | 설명 |
|---|---|---|
| 오픈 준비 | 20분 | 조명·간판·POS 켜기, 테이블 세팅 |
| 마감 정리 | 15분 | 매출 정산, 현금 시재 확인, 마감 보고 |
| 재고 확인 방법 | 10분 | 마감 체크리스트의 "콜라시럽 잔량 확인" 등 재고 항목을 확인하는 방법 |

### 고객 응대 (Customer Service)

| 제목 | 예상 소요시간 | 설명 |
|---|---|---|
| 손님 맞이 인사 | 1분 | 입장 시 인사말과 자리 안내 |
| 재방문 손님 응대 | 1분 | 단골 알아보기, 좋아하는 메뉴 언급 |
| 첫 방문 손님 응대 | 2분 | 메뉴 설명, 세트 구성 안내 |
| 음식 서빙 | 2분 | 서빙 순서, 손님 자리에 놓는 방법 |
| 예약 손님 응대 | 3분 | 예약 확인, 자리 준비, 응대 시 유의점 |
| 결제 및 만족도 확인 | 2분 | 결제 처리, 식사 만족도 짧게 확인 |
| 배웅 인사 | 1분 | 마무리 인사, 재방문 유도 멘트 |

### 주방 (Kitchen)

| 제목 | 예상 소요시간 | 설명 |
|---|---|---|
| 패티 손질/해동 | 15분 (냉장 해동 기준) | 냉동 패티를 안전하게 해동하는 순서와 시간 기준 |
| 버거 조립 | 5분 | 번 굽기 → 패티 → 야채 → 소스 순서, 완성까지 표준 조리 순서 |
| 감자튀김 조리 | 4분 | 튀김 온도·시간 기준과 담아내는 방법 |

### 위생 (Hygiene)

| 제목 | 예상 소요시간 | 설명 |
|---|---|---|
| 냉장고 청소 | 20분 | 주 1회 냉장고 내부 청소 및 유통기한 확인 |
